# raw/

Сюда кладут знание, которое некогда укладывать. **Правил нет:** любой формат, любое имя, без
frontmatter, без заголовков. Кусок вывода `systemctl`, три строки в блокнот, копия переписки —
всё годится.

Единственное, что здесь проверяется, — секреты: утечка одинаково необратима, лежит запись в
разобранном виде или нет.

## Зачем это существует

Запись со структурой требует решения «куда это», а в момент находки такого решения обычно нет.
Порог в две минуты раздумий — это ровно тот порог, на котором знание не записывают вовсе.

Инфраструктурное знание особенно ломкое: оно добывается прогоном на живой машине, живёт в
терминале и пропадает вместе с сессией. Строка вывода, которая объяснила поломку, через неделю
не воспроизводится — сервер уже починен.

## Как разбирать

```bash
python3 scripts/wiki-triage.py
```

Скрипт покажет, что накопилось, сколько лежит и в какие страницы просится каждая запись.
Ничего не переносит сам: кандидаты подбираются по совпадению слов, а это подсказка, а не диагноз
— слово «логи» встречается и у `nginx`, и у `cron`, и у `postgresql`.

Перенёс содержимое в страницу — удали запись отсюда.
