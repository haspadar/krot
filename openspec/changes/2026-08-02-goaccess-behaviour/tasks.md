# Tasks: человеческий отчёт по имени и поведению

## Реализация
- [x] Два прохода `awk` до GoAccess: первый считает запросы с внутренним referer по адресам,
      второй оставляет строки прошедших
- [x] `goaccess_humans_min_referers` (по умолчанию 2), уходит в юнит и в разовую сборку роли
- [x] Фильтр применяется **только** к человеческому отчёту; полный не тронут
- [x] `awk` сам проверяет формат строки (`!/^\[/ { next }`), не полагаясь на `grep` выше
- [x] Временный файл убирается вместе с `$lines`; переменная объявлена вне `if`, иначе
      `set -u` уронил бы скрипт при выключенном человеческом отчёте
- [x] Смена порога переписывает юнит и **пересобирает отчёты в том же прогоне** — юнит-задача
      теперь регистрируется, иначе новая настройка ждала бы таймера до часа
