# Пустой отчёт нового свойства GA4 доказывает доступ

## Why

Живая проверка после PR #98 показала, что новое свойство без событий отвечает на корректный
`runReport` без `metricHeaders` даже после того, как Viewer уже выдан и права дошли. Ответ
содержит `kind: analyticsData#runReport` и `metadata` свойства (валюту и часовой пояс), то есть
пришёл от настоящего Data API. Ожидание заголовка поэтому не завершается никогда: два живых
новых свойства читаются сборщиком, но запуск отказывает как будто доступа нет.

## What Changes

- Ответ Data API с `kind: analyticsData#runReport` и полноценной `metadata` считается успешным
  чтением пустого свойства даже без заголовка метрики.
- Непустой ответ без запрошенной метрики остаётся недействительным: страница прокси, чужой
  JSON или испорченный ответ не становятся доказательством доступа.
- Тест подделки Google воспроизводит живой ответ нового свойства.

## Не делает

- Не принимает любой HTTP 200, `{}` или произвольный JSON без признаков отчёта Google.
- Не меняет выдачу Viewer и обработку 4xx/5xx.
- Не выпускает версию и не двигает pin потребителя — это отдельный шаг.
