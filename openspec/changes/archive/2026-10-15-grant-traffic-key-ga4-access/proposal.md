# Заведение сайта само выдаёт сборщику трафика доступ к свойству GA4

## Why

Свойство GA4 заводится ключом запуска (`site_google_service_account`), а трафик сеть собирает
другим ключом — тем, что лежит на машине. Когда свойство заведено в Analytics-аккаунте, где у
ключа сбора нет прав (запуск ключом другого аккаунта), сбор отвечает 403 на каждом прогоне, и
`krot-traffic` красный каждый час. 07–15.10.2026 так было с одним сайтом: заведение рапортовало
успех, ошибка проявилась только следующей ночью, а доступ выдали руками через Admin API. Следующий
сайт из того же аккаунта повторил бы всё то же. Правило нужно на будущее: заведение не считается
законченным, пока тот, кто будет читать свойство, его не прочитал.

## What Changes

- **Новый модуль `ga4_access`**: читает свойство ключом сбора (Data API `runReport`). 200 — ничего
  не меняет. 403 «нет прав на свойство» — ключом запуска выдаёт ключу сбора роль viewer (Admin API
  `accessBindings`, только на это свойство) и перечитывает ключом сбора, пока доступ не появится.
- **`site_analytics` вызывает его после `ga4_property`**: результат — не рапорт выдачи, а успешное
  чтение ключом сбора.
- **Новый вход `site_ga4_reader_service_account`** — ключ, которым сеть собирает трафик. Обязателен,
  когда `site_analytics.ga4`: без него проверять нечем, а молчаливый пропуск и есть дефект.
  Проверяется в `site_preflight` до первой записи.
- Если выдать нельзя (ключ запуска не администратор свойства) или доступ не появился, запуск
  падает сообщением с адресом ключа сбора и ручным шагом, а не оставляет 403 на ночь.
- Сухой прогон (`--check`, preflight) говорит «выдача предстоит», ничего не записывая.

## Не делает

- Не выдаёт никаких ролей, кроме viewer, и никаких прав на аккаунт целиком.
- Не отзывает права и не правит чужие привязки.
- Не заменяет правило запуска «ключ запуска и ключ сети названы оператором до запуска»: оно
  остаётся в проектах.
- Не выпускает версию и не меняет закрепление коллекции в проектах — это отдельный релиз.

## Breaking

Новый обязательный вход при `site_analytics.ga4: true`: проекту нужно передать ключ сбора. Поэтому
следующий выпуск — major.
