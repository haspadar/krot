## Что нашлось двойным ревью

Проходы не пересеклись ни одной находкой. Codex смотрел выкатку, свой агент — механику:

- **reload без сервера по умолчанию** (Codex). Скрипт real-IP перезагружает nginx сам и стоял
  раньше default server — в окне выкатки reload ушёл бы в конфиг вовсе без 444. Default server
  теперь ставится первым;
- **сбой reload становился «без изменений»** (Codex). Файл уже на диске, копия удалена — и
  следующий запуск видел совпадение и выходил с 0 на старых диапазонах. Теперь при сбое reload
  возвращается прежний файл;
- **выключение не останавливало идущий запуск** (Codex) — останавливается и сервис;
- **гонка роли и таймера** (агент) — `flock`;
- **нечитаемый файл читался как «чужих нет»** (агент): `find` отдаёт 1 и на «не нашёл», и на
  «не прочёл». Отказом теперь считается непустой stderr.

Отклонены: лишний reload за прогон (шум, оба проходят `nginx -t`); `listen` на двух строках
(генераторы сети так не пишут, `nginx -t` хендлера всё равно остановит reload); хрупкий
`grep -c` (недостижимо, пока `validate` требует оба семейства).
