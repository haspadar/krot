### Что нашлось двойным ревью PR 1

Codex сверял факты с busel, свой агент — устройство. Совпал у них один пункт.

Принято:

- **У IndexNow `quotaWasAsked` — `true`** (Codex). Вики busel пишет `false`, код — `true`;
  change повторил вики. Прав код: 10 000 названы протоколом;
- **403 и 422 IndexNow — разные отказы** (Codex): ключ против адресов чужого хоста;
- **«Не принято ничего» краснит только при попытке без причины** (оба): пустой сайт и
  кончившаяся норма зелёные — иначе правило противоречило соседнему;
- **Доля Google — с отбрасыванием остатка** (Codex): округление вверх даёт 201 из 200;
- **Отказ записи строки страницы — красный** (агент): на ней держится удержание, и проглоченный
  он тратил бы норму на повторы зелёным. Проглатывается только итог ночи — как в busel;
- **Отправка пишет `submitted_at` у всех движков** (агент): иначе у неопрашиваемых нет удержания;
- **Роль Postgres, peer, порядок проверок, `ALTER DEFAULT PRIVILEGES`** (агент);
- **Doctrine проекта должен не видеть схему `krot`** (агент) — требование к потребителю;
- **Перевод busel: снять старый таймер → копия → новый, все сайты движка разом** (агент):
  «копия прямо перед сменой» не была атомарной;
- **Один ключ — один проект, роль сверяет** (агент): имя проекта в инвентаре не гарантирует
  отдельного Cloud-проекта;
- **Ключ Google — файлом, не строкой `EnvironmentFile=`; движки — явным списком** (агент):
  пустой ключ выключал бы движок молча, вопреки `secrets.md`;
- **Свой маркер юнитов и имя проекта без дефиса** (агент): старые `krot-index-*` busel от роли
  `cron` не должны сниматься по совпадению имени.

Отклонено:

- **Править принцип в `collection-layout.md` уже в PR 1** (агент). Вики описывает машину, какая
  есть, а роли ещё нет; решение записано в `proposal.md`, страница правится в PR роли — как у
  `site-launch`: принцип там переписан отдельным коммитом, когда роли появились;
- **`Persistent=false` для таймера Google** (агент). Догоняющий прогон всегда идёт после
  какого-то сброса нормы, а лишний прогон в те же сутки находит её потраченной и зелёный.
  Выключенный догон терял бы ночь целиком.

Побочная находка — **вики busel разошлась с кодом** в двух местах (`quotaWasAsked` у IndexNow,
403/422 одной строкой); передать в busel.

### Что нашлось двойным ревью PR 2

Codex сверял порт с busel, свой агент искал тихие отказы. Первая находка у обоих одна.

Принято:

- **Принятое до отказа посреди пачки терялось** (оба). Google отправляется по странице; отказ
  на тридцатой уносил двадцать девять принятых — ни строки, ни удержания, завтра повтор.
  Теперь отказ несёт принятое (`Refused.accepted`), и оно записывается. **В busel тот же
  дефект** — передать;
- **Sitemap доверял чужим адресам** (Codex): вложенный файл с другого хоста читался, страница
  чужого домена уходила движку под свойством сайта, а настоящие страницы забывались.
  Теперь вложенные файлы — только с хоста объявленного адреса, страницы — только с домена;
- **Сбои вне `URLError`** (агент): оборванное тело, кривой адрес ломали обход всей ночи.
  Теперь это недоступность одного запроса; любая ошибка одной инспекции — `unasked` этой
  страницы;
- **Схемы кроме http/https и тело без предела** (агент): `file://` из индекса sitemap
  открывался; ответ читается не больше 50 МБ — потолок самого протокола sitemap;
- **429 опроса читался как молчание и красил юнит** (агент) — теперь `throttled`;
- **Токен не обновлялся после часа** (агент) — перевыпускается через 50 минут;
- **`.xml.gz` краснил здоровый сайт** (агент) — распаковывается, с тем же потолком;
- **Пустой текст ошибки ронял «сказать и идти дальше»** (агент) — `first_line`;
- **Версия схемы на миг пустела при повторном накате** (агент) — смена в одной транзакции;
- **Кривая регулярка в конфиге ломала ночь на середине** (агент) — проверяется до обхода.

Отклонено:

- **Порог на «сайт вдруг отдал меньше страниц» перед `forget_gone`** (агент). Так же устроен
  busel, а порог держал бы строки страниц, которые сайт убрал намеренно (снятые номера gudok).
  Цена ложного забывания — повторная отправка, а не вред сайту;
- **Закрывать соединение с базой** (агент) — процесс одноразовый и завершается сразу после
  обхода.

### Что нашлось двойным ревью PR 3

Codex сверял порт с busel, свой агент искал тихие отказы. Общая у них одна находка — потолок
IndexNow.

Принято:

- **Bing принимал за успех любой JSON без целого `ErrorCode`** (агент): 500 от WCF или прокси
  с `{"Message": …}` становился «принято всё», страницы уходили в удержание, ночь зелёная.
  Теперь успех — только 200 без кода; код строкой (`"14"`) тоже отказ. **В busel так же**;
- **Три попытки нормы Bing считались по вызовам, а не по сайтам** (агент): обход спрашивает
  норму сайта несколько раз, и два сайта без ответа выключали вопрос для всех остальных;
- **«Не удалось спросить норму» смотрело только на последний сайт** (агент) — теперь строка
  у каждого такого сайта;
- **Яндекс: 401, 403 и 429 без `error_code` считались отказом одной страницы** (агент) —
  отозванный токен тратил 150 попыток на сайт. Теперь это отказы с починкой;
- **Хост Яндекса брался первым по имени** (агент): старый `http:`-хост рядом с `https:`
  отклонял каждую страницу поштучно. Теперь `https` первым, список хостов — раз за прогон;
- **Сбой чтения тела отказа уходил мимо `Unreachable`** (агент): таймаут посреди тела 5xx
  останавливал обход всех сайтов. Оборванное тело `read(n)` при этом отдаёт молча — эта
  часть находки не подтвердилась, подтвердилось зависание;
- **Текст `Unreachable` нёс адрес целиком, у Bing — с ключом** (агент): держалось только на
  том, что вызывающий глотает текст. Теперь строки запроса в сообщениях нет;
- **Файл-ключ IndexNow с 5xx или недоступный считался чужим ключом** (агент): починка
  отправляла к маршруту, который цел. Теперь это «не принято» — ночь красная без ложной починки.

Отклонено:

- **Потолок 10 000 IndexNow как ночная норма** (оба; Codex — «no-ship»). Так же в busel, и
  это намеренно: одна отправка на сайт за ночь, остаток уходит в следующие ночи, а с
  удержанием 14 дней сайт до 140 000 страниц предлагается целиком каждые две недели.
  Неверны были комментарии, говорившие «не ночная норма», — переписаны, потолок закреплён
  тестом. Codex сам допускал этот путь: «document and justify a deliberate per-run cap»;
- **Запоминать страницы, которые Яндекс отверг поштучно** (агент). Страницы берутся только
  из sitemap сайта с проверкой домена, поштучный отказ редок; систематический виден как
  «ничего не принято».

Уточнено без смены поведения: 5xx IndexNow красит ночь через «ничего не принято», а
комментарий утверждал обратное.

### Что нашлось двойным ревью PR 4

Codex смотрел как оператор живой машины busel и gudok, свой агент — корректность Ansible и
тихие отказы. Пересечений нет.

Принято:

- **Ключи утекали через упавший элемент цикла** (агент, воспроизведено): `label` укорачивает
  только строки ok/changed, а упавший элемент печатается целиком — с закрытым ключом Google.
  Циклы теперь идут по `indexing_plans`, проекции без ключей;
- **Чужая схема `krot` перенималась** (Codex): `postgresql_schema` с `owner` делал `ALTER
  SCHEMA … OWNER`. Теперь схема другого владельца — отказ до изменений;
- **Уборка удаляла любой файл в `/etc/krot-index`** (Codex) — теперь только три своих имени;
- **`reader` без `CONNECT`** (Codex): при отозванном у PUBLIC доступе к базе все гранты на
  схему бесполезны. Роль даёт `CONNECT` и ему; сценарий гоняется с отозванным;
- **Проверки базы и `reader` шли после первых правок** (Codex) — теперь все проекты
  проверяются до учётки, роли Postgres и программы; остаются только пакеты;
- **Роль `krot_index` сохраняла чужие атрибуты** (Codex) — теперь все `NO*` названы явно;
- **Изменённое расписание не доходило до запущенного таймера** (агент) — изменённый таймер
  перезапускается;
- **`$` в регулярках пропускал `\n` на конце** (агент, проверено) — `\Z`;
- **`__pycache__` тестов уезжал на машину** (агент) — тесты `indexing` байткод не пишут;
- **Пробелы сценария** (агент): Google не ставился вовсе, уборка проверялась на одном файле,
  «ни одной чужой таблицы» проходило на пустой схеме — дополнено.

Отклонено:

- **Членство `krot_index` в привилегированных ролях** (Codex, часть находки). Атрибуты теперь
  названы; членства роль сама не выдаёт, а чужую роль с этим именем на машине, где её никто не
  заводил, искать — уже не проверка роли;
- **Check mode на голой машине** (агент) — так же у `cron`: учётка появляется только прогоном;
- **Отказ одного проекта задерживает уборку остальных** (агент) — намеренно: сперва
  проверки, потом правки;
- **Удалённые из программы модули остаются на машине** (агент) — `copy` не удаляет; цена —
  лишний файл, который никто не импортирует.

Отказ на чужой схеме в сценарии не гоняется: упавший converge пришлось бы ловить отдельным
сценарием, а проверка — один `assert` над одним запросом.
