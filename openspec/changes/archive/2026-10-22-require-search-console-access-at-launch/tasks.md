## Ревью

Codex (атакующая роль) и свой агент (корректность, интеграция, достоверность документации).

- Принято: флаг выдачи в плейбуке перекрывал `--check` — теперь `--check` сильнее, тест.
- Принято: любой 403/404 Site Verification считался «не владелец» — теперь только 403 «You are
  not an owner of this site.» (замер 22.10.2026), прочее падает с причиной Google; тест.
- Принято: после записи владельцев проверяется, что все прежние остались; `added` в общем
  отказе; ожидание владения — `site_search_wait_*`; отчёт плейбука пишет `FAILED: <причина>`;
  источники цитат 403 в вики.
- Принято частично: гонка между чтением и заменой списка владельцев. Добавить одного владельца
  API не умеет, список меняется только целиком, так же пишет `gsc_site`. Риск записан в справку
  модуля и вики, окно — один запрос одного запуска.
- Отклонено: «preflight пропускает подтверждённый сайт, где ключ запуска не владелец». Запуск сам
  подтверждает домен ключом запуска (TXT в своей зоне) до выдачи, поэтому выдать он сможет;
  строка отчёта теперь называет этот путь (`becomes owner once the domain is verified`).
- Не закрыто: ветка `site_search_console_off_reason` и её строка отчёта не гоняются ни
  molecule, ни pytest (сценарий запускает сайт с Google).
